# HRmony AI (Organizational Digital Twin & HR Decision Intelligence)

> **「AI 기반의 동적 이중경력경로(Dynamic Dual Career Path) 및 맞춤형 학습·경력개발 플랫폼 구축: 역량 중심 재숙련, 객관적 HR 파이프라인 및 AI 시뮬레이션 검증」** 연구 제안서 공식 실증 시뮬레이터

---

## 📌 주요 특징 및 기능

1. **4대 설계 모듈 통합 폐루프(Closed-Loop) 아키텍처**
   - **[모듈 1]** 행동 로그 기반 IC vs Manager 실시간 성향 분석, 마이크로 KPI, 기술 권위 매칭 및 커리어 피벗 시뮬레이터
   - **[모듈 2]** 성향·역량 맞춤 온보딩, AI 기술 반감기 조기 경보, 인접 역량 기반 JIT 동적 재숙련 및 RAG 사내 AI 튜터화
   - **[모듈 3]** 직무 성과 원화(억원) 재무 환산, L5~L8 통합 레벨링, 안건별 결재권 분리 및 전문가 거부권(Veto), RAG 재사용 로열티 보상
   - **[모듈 4]** 멀티 에이전트(N=500) 디지털 트윈 가상 조직 A/B 시뮬레이션 및 HR 의사결정 인텔리전스 환류

2. **제안서 1:1 매칭 6대 탭(Tab) 화면**
   - **[Tab 1] 아키텍처 & 로직맵**: `<그림 1>` 4단계 폐루프 전체 아키텍처 & `[도식 2]` 에이전트 월 단위 상태 전이 순서도
   - **[Tab 2] Twin Organization A/B 메인**: `[화면 캡처 1]` Control vs Treatment 실시간 에이전트 분포도 및 L5~L8 통합 매트릭스
   - **[Tab 3] 5대 인사 난제 정량 검증**: `[화면 캡처 2]` & `<표 4>` 60개월 정량 지표 요약표 및 2×2 인터랙티브 Plotly 차트
   - **[Tab 4] 선제적 핀셋 리텐션 & 정책 샌드박스**: `[화면 캡처 3]` Flight Risk 조기 경보 Top 10, AI 리텐션 처방 시뮬레이터 및 로열티-승격 커트라인 히트맵
   - **[Tab 5] Buy vs Build · TF 케미스트리 · CFO ROI**: `[화면 캡처 4]` 인력 수급 최적화 도넛, 5각 레이더 케미스트리 및 3개년 CFO 워터폴 차트
   - **[Tab 6] 임직원 개인용 XAI 마이 커리어**: `[화면 캡처 5]` 개인 행동 로그 진단, 실시간 RAG 로열티 정산 및 3개년 커리어 패스 비교

## 🚀 실행 가이드

### 1. 패키지 설치
```bash
pip install streamlit plotly pandas numpy
```

### 2. 애플리케이션 실행
```bash
streamlit run app.py
```
브라우저에서 `http://localhost:8501`로 접속하여 확인합니다.
